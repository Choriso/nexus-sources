## О проекте

**3D Print Calculator** — это полностью клиентское веб-приложение для расчёта стоимости 3D-печати. Состоит из двух страниц:

| Страница | Назначение |
|----------|------------|
| `index.html` | Клиентский калькулятор — любой человек может загрузить, ввести размеры модели и мгновенно получить стоимость |
| `admin.html` | Панель администратора и исполнителя — управление исполнителями, материалами, ценами, генерация ссылок |

Архитектура **zero-backend**: все данные хранятся в `localStorage` или передаются через URL. Приложение работает на GitHub Pages без сервера и базы данных.

## Возможности

### Для администратора
- **Управление исполнителями** — добавляйте, настраивайте, удаляйте исполнителей
- **Гибкая настройка материалов** — для каждой технологии (FDM, SLA, SLS) свои материалы с индивидуальными ценами, плотностью, цветами
- **Привязка технологий** — FDM (PLA, PETG, ABS, TPU, Nylon, ASA, PC), SLA (фотополимеры), SLS (нейлоны)
- **Настройка качества и заполнения** — мультипликаторы цены и времени для разных параметров печати
- **Генерация ссылок** — создавайте персональные ссылки для исполнителей с предустановленными настройками
- **QR-коды** — каждая ссылка сопровождается QR-кодом (генерируется на устройстве, без внешних API)
- **Отзыв доступа** — мгновенно отзывайте старые ссылки исполнителей и ссылки их клиентов

### Для исполнителя
- **Персональный кабинет** — вход по уникальной ссылке от администратора
- **Редактирование профиля** — название, email, Telegram, телефон
- **Самостоятельная настройка** — цены, материалы, цвета, параметры печати
- **Генерация клиентских ссылок** — создавайте ссылки для своих клиентов с вашими ценами
- **QR-код** — для печати или отправки клиентам

### Для клиента
- **Мгновенный расчёт** — введите габариты модели, выберите материал и параметры
- **Детальные описания** — подсказки по каждой технологии, материалу, качеству печати
- **Выгрузка заказа** — сформируйте текстовый файл с параметрами для отправки исполнителю
- **Работает везде** — на телефоне, планшете, компьютере

## Архитектура

### Ключевые особенности реализации

- **Без сервера** — вся логика выполняется в браузере
- **Diff-кодирование конфигов** — настройки передаются в URL в виде компактного diff'а, что позволяет уместить конфиг в QR-код
- **Криптостойкая аутентификация** — ключ доступа формируется хеш-функцией на основе SALT и версии
- **Система отзыва** — два уровня: глобальный (ACCESS_SALT) и per-executor (версия конфига)
- **Полностью на русском языке** — интерфейс, описания, подсказки

## Быстрый старт

### Развёртывание на GitHub Pages

```bash
git clone https://github.com/ваш-username/3dprint-calc.git
cd 3dprint-calc
# Просто запушите на GitHub Pages
git push origin main
```

Всё! Страницы доступны по адресу:
- `https://ваш-username.github.io/3dprint-calc/` — клиентский калькулятор
- `https://ваш-username.github.io/3dprint-calc/admin.html` — панель управления

### Локальный запуск

Просто откройте `index.html` или `admin.html` в браузере. Для работы QR-кодов и полной функциональности необходим доступ в интернет (загрузка QRCode.js с CDN).

### Первый вход

1. Откройте `admin.html` и войдите как администратор: `admin` / `admin123`
2. Вкладка **«Исполнители»** → создайте нового исполнителя
3. Настройте технологии, материалы и цены через кнопку **«Настроить»**
4. Скопируйте ссылку **«Логин»** и отправьте исполнителю
5. Исполнитель переходит по ссылке, настраивает профиль и генерирует **«Ссылку клиенту»**
6. Клиент переходит по ссылке и рассчитывает стоимость печати

## Безопасность

> Важно: перед использованием в production смените значения по умолчанию

| Параметр | По умолчанию | Где изменить |
|----------|-------------|--------------|
| Логин администратора | `admin` | `admin.html` (строка `ADMIN_USER`) |
| Пароль администратора | `admin123` | `admin.html` (строка `ADMIN_PASS`) |
| ACCESS_SALT | `'3dprint_salt_2024_change_me'` | `admin.html` и `index.html` |

После смены ACCESS_SALT все существующие ссылки исполнителей станут недействительными — нужно заново сгенерировать ссылки для входа.

## Технологии

| Технология | Применение |
|------------|------------|
| **HTML5 / CSS3** | Разметка и стилизация (vanilla, без фреймворков) |
| **Vanilla JavaScript** | Вся логика (никаких зависимостей, кроме QR-кодов) |
| **QRCode.js** | Генерация QR-кодов (cdnjs) |
| **GitHub Pages** | Хостинг и деплой |
| **localStorage API** | Хранение конфигов, сессий, whitelist |
